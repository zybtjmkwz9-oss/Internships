# Portfolio site

This repository now contains a simple, static portfolio website you can publish with GitHub Pages.

What I added

- index.html — main page with About, Projects, Contact
- assets/styles.css — styles
- assets/script.js — small JS for modal and footer year

How to publish

1. Open the repository on GitHub: https://github.com/zybtjmkwz9-oss/Internships
2. Go to Settings → Pages (or Pages in the left sidebar).
3. Under "Branch", select the `gh-pages` branch and the root `/` folder, then Save. GitHub will publish the site at `https://zybtjmkwz9-oss.github.io/Internships/` (it may take a minute).

How to customize

- Replace `Your Name`, `your.email@example.com`, and the placeholder texts in `index.html` with your real info.
- Replace images (currently placeholder images) with screenshots in a new `assets/images/` folder and update the `src` attributes.
- Add or remove projects by editing the `<article class="project-card">` elements.
